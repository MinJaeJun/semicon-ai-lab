# YieldLens — 다단 공정 수율 원인 인자 추적

24개 대표 스텝을 거친 웨이퍼 12,000장에서 **수율을 떨어뜨리는 진짜 원인 인자를 찾아낸다.**

```bash
python generate.py   # 데이터 생성 + 자체 검증
python analyze.py    # 스크리닝 → 교란 제거 → 운전구간 도출 → 수율 예측
```

## 문제

공정 데이터에서 원인 인자를 찾는 일은 상관계수를 정렬하는 것으로 끝나지 않는다.
이 데이터에서 상관 스크리닝을 그대로 돌리면 **46개 계측 인자 중 46개가 유의하게 나온다.**

이유는 교란이다. Lot 건강도가 나쁘면 계측값도 나빠지고 불량률도 같이 나빠진다.
그래서 아무 관계 없는 인자까지 전부 수율과 상관된 것처럼 보인다.

## 접근

**특정 불량모드와의 상관에서 전체 수율과의 상관을 뺀다.**

```
specificity = max|rho(인자, 불량모드 i)| − |rho(인자, 전체수율)|
```

진짜 원인 인자는 특정 불량모드에 붙어 있으므로 이 값이 양수다.
교란으로만 엮인 인자는 전체 수율 쪽 상관이 더 강하므로 음수가 된다.

## 결과

| 단계 | 후보 수 |
|---|---:|
| 전수 검정 (46 인자 × 6 타깃) | 276 조합 |
| BH-FDR q ≤ 0.05, \|rho\| ≥ 0.15 | 46 인자 |
| **specificity > 0 필터 후** | **5 인자** |

정답은 5개다. 결과는 **precision 1.00 / recall 1.00 / 오탐 0건.**

상관 스크리닝만으로는 46개가 남는다. specificity 부호 하나로 그중 41개를 정확히
떨어내고 진짜 5개만 남긴다.

### 검출된 원인 인자와 권장 운전구간

`outputs/control_windows.json` 에 인자별 최적 중심, 권장 구간, 현재 중앙값,
조정 방향(높여야 함 / 낮춰야 함 / 유지)이 들어 있다.

네 인자 모두 **U자 응답**이다. 최적 구간이 있고 양쪽으로 벗어나면 나빠진다.
그래서 "값을 낮추세요" 같은 단방향 지시가 성립하지 않고, 구간으로 답해야 한다.
2차 적합으로 복원한 최적점은 실제 심어둔 값(48.0 / 71.5 / 34.0 / 62.0) 대비
46.3 / 69.5 / 32.9 / 57.3 으로, 최대 오차 4.7 이내다.

### 수율 예측

| | MAE | R² | 위험 Top30 정밀도 |
|---|---:|---:|---:|
| 결측 지시자 포함 | **2.67 %p** | **0.621** | **92.7%** |
| 결측 지시자 제거 (대조군) | 2.70 %p | 0.611 | 94.0% |

Lot 단위 GroupKFold. **결측 여부 자체를 피처로 넣었다.** 계측이 MNAR 이라
"안 쟀다" 는 것 자체가 "안전해 보였다" 는 정보이기 때문이다.

R² 0.62 는 높은 수치가 아니고, 그게 정상이다. 계측률이 22% 라 웨이퍼 한 장의
수율을 정확히 맞추는 건 원래 불가능하다. 이 모델의 쓰임새는 절대값 예측이 아니라
**검사 우선순위 정렬**이고, 그 지표가 Top30 정밀도 92.7% 다.

결측 지시자를 넣은 효과는 R² 에서 +0.010 에 그쳤고 Top30 정밀도는 오히려 1.3%p 낮았다.
기대만큼 극적이지 않았고, 그대로 적는다.

## 데이터

`data/wafer_history.csv.gz` — 12,000행 × 84열 (500 Lot × 24 Wafer)

```
ID(3)        Wafer_ID, Lot_ID, Slot
Config(24)   Step{n}_Config = "S{n}|{TOOL}|{CH}"
             Tool 은 Lot 단위 고정, Chamber 는 Wafer 단위 변동
Response(38) Step{n}_R{1,2,3}  계측률 약 22%
Defect(8)    Step{n}_D1        계측률 약 8%
Target(11)   Yield_pct, FR_{BRIDGE,VOID,PARTICLE,SHORT,OPEN},
             FB_{...} (불량모드별 Fail Bit Count)
```

불변식: `Yield_pct + sum(FR_*) == 100.0` (전 행 정확히 성립)

`data/wafer_history_holdout.csv` — 1,080행, 타깃 제거본.
정답은 `data/holdout_answers.csv` 에 따로 있다.

## 데이터에 심어둔 어려움

1. **MNAR 계측** — 위험한 웨이퍼일수록 자주 잰다. 계측된 웨이퍼의 평균 수율이
   미계측 웨이퍼보다 4.4%p 낮다. 계측 데이터만 보면 라인이 실제보다 나빠 보인다.
2. **U자 응답** — 원인 인자 4개가 전부 최적점 기준 2차 응답. 단조가 아니다.
3. **교란** — Lot 바이어스가 계측값과 불량률을 동시에 민다.
4. **스펙 클리핑** — 무관한 인자는 스펙 경계에서 값이 잘린다.
5. **슬롯 효과** — 캐리어 가장자리 슬롯(1, 2, 23, 24)이 구조적으로 불리하다.
