# EtchPilot — Etch 레시피 품질 사전 예측

레시피를 실제로 돌리기 전에 결과를 예측하고, 어느 파라미터를 어느 방향으로
조정해야 하는지 추천한다.

```bash
python generate.py   # 4공정 데이터 생성 + 검증
python analyze.py    # 예측 → 레시피 순위 → OFAT 추천
```

## 문제

레시피 최적화는 웨이퍼를 태워가며 한다. 조건 하나 바꾸고 돌려보고, 결과 보고,
다시 바꾸고 돌린다. 축적된 평가 이력이 있는데도 다음 조건 결정에 잘 활용되지 못한다.

## 접근

**웨이퍼 평균이 아니라 사이트 단위로 예측한 뒤 집계한다.**

같은 평균이라도 산포가 다르면 전혀 다른 레시피다. 중심은 맞는데 엣지가 벌어지는
레시피와, 전체가 균일하게 살짝 치우친 레시피는 대응 방법이 다르다.
그래서 29개 사이트를 각각 예측하고 웨이퍼 단위로 올린다.

입력은 레시피 파라미터 + **사이트 좌표(반경/각도/존)** + 장비/챔버다.

## 결과

### 예측 성능 (미학습 레시피 대상)

리비전 단위 LeaveOneGroupOut. 모델은 평가 대상 레시피를 한 번도 본 적이 없다.

| 공정 | 항목 | MAE | 기준선 | 개선 |
|---|---|---:|---:|---:|
| poly | Top CD | 0.739 | 1.205 | **−38.7%** |
| poly | Depth (Å) | 49.50 | 61.80 | **−19.9%** |
| via | Depth | 55.92 | 66.03 | **−15.3%** |
| via | Bottom CD | 4.308 | 5.012 | **−14.0%** |
| pad | Mid CD | 30.69 | 35.45 | −13.4% |
| contact | Top CD | 1.345 | 1.441 | −6.6% |
| contact | Bottom CD | 2.824 | 2.859 | −1.2% |
| **pad** | **Bottom CD** | 63.67 | 62.93 | **+1.2% (악화)** |
| **pad** | **Depth** | 136.3 | 128.8 | **+5.8% (악화)** |

기준선은 "전체 중앙값으로 찍기". 16개 조합 전체는 `outputs/model_report.json`.

**pad 공정은 예측이 안 된다.** Bottom CD 와 Depth 둘 다 기준선보다 나쁘다.
Stage 가 1개뿐이라 레시피 파라미터가 5개밖에 없고, 미학습 리비전으로 외삽할 신호가
부족하다. 이 항목은 "예측 가능" 이라고 주장하지 않는다.

전반적으로 **Top CD 는 잘 맞고 Bottom CD 로 갈수록 나빠진다.** 식각 깊이 방향으로
갈수록 레시피 파라미터로 설명되지 않는 요인이 늘어난다는 뜻이다.

### 레시피 순위와 OFAT 추천

`outputs/recipe_ranking.csv` — 12개 리비전을 동일한 품질 점수로 환산해 줄 세운다.

```
종합 점수 = Pass Rate 60% + Uniformity 25% + 목표 근접도 15%
  Uniformity      : 사이트 간 변동계수를 허용치(3%) 기준 선형 정규화
  목표 근접도     : 스펙 중앙 대비 오차, ±5% 벗어나면 0점
```

`outputs/ofat_recommendation.json` — 최하위 레시피에 대해 파라미터를 **하나씩만**
±6% 흔들어보고 예상 점수 변화를 낸다. 한 번에 여러 개를 바꾸면 원인을 못 가리기
때문에 현장에서도 OFAT 로 한다.

리비전마다 1~3개만 바뀌므로 "이 파라미터를 바꿨더니 품질이 어떻게 변했나" 를
되짚을 수 있다.

## 데이터에 심어둔 성질

1. **엣지 프로파일** — 반경² 에 비례해 CD 가 벌어지고 Defect 이 증가한다.
   Center 0.11건 → Extreme Edge 0.77건.
2. **장비/챔버 바이어스** — 같은 레시피도 챔버에 따라 결과가 다르다.
   이걸 모르면 "레시피가 나쁘다" 와 "챔버가 나쁘다" 를 구분 못 한다.
3. **Depth 단위 불일치** — poly 만 Å, 나머지는 nm. 실제로 자주 겪는 함정이다.
4. **점진적 레시피 변경** — 리비전당 1~3개 파라미터만 변경.
